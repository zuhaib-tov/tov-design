# Component Changelog

Tracks design-level changes to individual components and variants, across
every Figma system in `FIGMA_SYSTEMS.md`. That file tracks Figma→code
*transfers*; this one tracks changes *inside* Figma itself, component by
component, so there's one place to see what moved recently without opening
every file.

## How it works

- Whenever a component/component-set's design changes (new variant, restyle,
  status flip, etc.), its Figma `description` field gets a short dated note
  (visible in Figma's inspect panel on the component itself) — and the same
  change gets a row below.
- Status labels:
  - 🆕 **New** — just created
  - 🔁 **Updated** — existing component, design changed
  - ✅ **Stable** — exists, no recent change
  - 🚧 **Draft** — not yet finalized (mirrors the `Status=Draft` variant property)

This is v1 of the tracker Shay asked to keep — manually logged at the point
of change for now, not yet automated off Figma's own version history. See
the open questions still noted for a future automated pass.

**This file is the narrative record** (good for git history/PR review).
**The actual UI** — a visible table at the bottom of every synced doc page,
via `<ChangeLogTable page="..." />` — reads from `src/lib/changelog.ts`
instead, since a page can't render markdown. Log a change in **both**
places: a row here, and a matching entry in that file (same date, same
component, same summary).
